# 柏宝绘 · 流式重构版 0.4.23

安装／更新链接：https://github.com/stilljy-commits/ST-BaiBai-Image

配图独立读取主 API 已返回的正文，tags 分析和出图不再等待图片卡片显示、滚动或绘制。尾批及时放行，返回前台自动恢复，并保护正文收尾时的图片落位。旁读同一份主 API 返回，不增加主 API 请求，沿用现有副 API、模型、提示词和合批设置。

静默请求、其他聊天和取消任务不会混入当前正文；重复通知不会重复派发。保留原通知路径作兼容后备，预览异常不打断生成。此前未确认的其他提示词和 NAI 传输审计改动不包含在本版。

[完整版本说明](./RELEASE-0.4.23.md)。独立候选版 1,269 项测试通过、3 项既有跳过；类型检查、生产构建及浏览器模拟验证通过。约 5.1 万字、10 张图的浏览器测试中，不滚动、不挂载卡片也完成了全部本地模拟生图请求。没有调用真实模型或 NAI 付费接口。

手机 TT 尚未实机验证。若 Android 暂停整个插件脚本，插件仍不能保证离开 APP 后全程生成。更新后完全退出并重开 TT，确认版本显示 0.4.23，再用新一轮长正文体验。
