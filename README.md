# 柏宝绘 · 流式重构版 0.4.22

安装／更新链接：https://github.com/stilljy-commits/ST-BaiBai-Image

普通自动出图及备用整楼分析、编辑提示词后重新生成，在提示词保存成功后即进入任务队列，不再等待图片卡片挂载或滚动到对应位置。手动出图共用相同任务实现。

流式主流程继续独立于页面位置；等待 NAI 并发名额时如实显示“排队中”，真正开始请求时才显示“生成中”。新增请求时间记录以帮助区分调度与显示延迟。模型、提示词、NAI 并发和请求间隔保留，不增加语言模型分析请求。

[完整版本说明](./RELEASE-0.4.22.md)。独立候选源码验证：91 个测试文件，1,227 项通过、3 项既有跳过；类型检查和生产构建通过。覆盖长正文 20 张图不挂载、不滚动仍能生成，以及保存后页面显示流程阻塞等场景。

尚未在出问题的手机 TT 上验证，不能把自动测试当作手机故障已经消失的证明。更新插件后刷新客户端，用新一轮长正文、不滑到底来测试。自动出图沿用现有开关，不自动重跑历史楼层。此前未确认的其他提示词和 NAI 传输审计改动不包含在本版。
