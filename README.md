# 柏宝绘 · 流式重构版 0.4.14

安装／更新链接：https://github.com/stilljy-commits/ST-BaiBai-Image

渠道 → NAI → 漫画模式中，原 NSFW 工程规则升级为“画面工程规则（通用 + NSFW）”，一个开关统一控制，沿用原开关选择。通用要求用于所有画面，专项按场景适用。

漫画模式附加规则支持五个可命名页签，可直接用中文或英文保存不同作品的画面需求，只有当前组用于新启动的分析任务。旧内容迁移到第 1 组，空白组不追加规则；各组内容与当前选择自动保存。页签只控制附加规则文本，其他插件参数仍共用。

标准、简单、极速模式均使用当前组；已有流式生图及正文预览功能保留。

[完整版本说明](./RELEASE-0.4.14.md)。验证：81 个测试文件，1,067 项通过、3 项原有跳过；类型检查、构建通过，Chrome／Edge 各 8 项场景通过。本次没有向真实模型或 NAI 发起出图测试，规则注入不代表图片一定精准还原。
