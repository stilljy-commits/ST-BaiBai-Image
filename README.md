安装／更新链接：https://github.com/stilljy-commits/ST-BaiBai-Image

修复正文流式生成时图片已经显示，但正文结束后丢失的收尾交接问题。覆盖最终清理移除 img 标记、标记仅空格变化、宿主初始化第一条候选回答，以及保存图片位置后监听器写回旧正文的情况。

只在同一条回答、正文内容一致时恢复已接收的图片位置，复用已完成的任务；不增加 AI 分析或 NAI 生图请求。正文被真正修改、删除或切换回答时不强行套入旧图。一次收尾最多补写一次，不持续争抢正文。

本次只发布图片丢失修复，提示词、负面词、画师词与 NAI 参数沿用 0.4.18；待研究的提示词改动未发布。模型、合批数量、并发和现有显示开关均沿用原配置。
