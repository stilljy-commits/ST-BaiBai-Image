# 柏宝绘 · 流式重构版 0.4.24

安装／更新链接：https://github.com/stilljy-commits/ST-BaiBai-Image

在「NAI → 配置 → 接入点」下方显示当前账号的 Anlas 总余额，以及订阅和购买余额。账号支持时同时显示 V5 免费额度百分比和默认参数估算张数，额外额度单独列出。免费张数随模型、尺寸和步数变化，接口未返回的数值不会当作零。

支持自动、手动刷新；切换接入配置、修改地址或密钥时立即清空旧结果并取消旧查询，避免混淆账号。配置展开且页面可见时每分钟检查刷新；关闭设置清理查询和定时器。查询失败给出提示，同账号的上次读取结果会标注保留。查询只读取账户信息，不调用主副模型，不发送生图请求。

修正「测试连接」的订阅查询路径，兼容站保留自身域名和基础路径；未实现余额查询接口的兼容站无法显示。本版沿用 0.4.23 的生图流程，未确认的提示词、传输及其他审计改动没有包含在本版。

[完整版本说明](./RELEASE-0.4.24.md)。独立发布候选版 1,306 项测试通过，3 项既有跳过；类型检查、生产构建、8 项浏览器界面验证通过。界面验证覆盖账号切换、旧请求延迟返回、查询失败、缺失及零余额、关闭清理，以及窄屏与日夜主题。使用模拟数据，没有调用真实 NAI 或付费生图接口。

真实账号及手机 TT 尚未实测。更新后重开 TT，确认插件版本为 0.4.24，在 NAI 配置中查看余额。
