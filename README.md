# 柏宝绘 · 流式重构版 0.4.20

安装／更新链接：https://github.com/stilljy-commits/ST-BaiBai-Image

修复同一轮漫画生成中，跨图、跨批简写衣着后丢失 cosplay 对象、作品和服装版本的问题。来源与可见衣着分开维护；特写不清除，明确结束或更换对象才更新，不修改原创人物自己的永久身份。

加强逐人物衣着归属与少量可靠的互斥排除，保护共享衣物和本人正确特征。标准、简单、极速三种漫画模式及 V1／V2 均生效，无需新开关。并行分析继续保留；需要继承衣着时仅等待前批分析，不等待前批图片，不增加 AI 请求。

[完整版本说明](./RELEASE-0.4.20.md)。验证：89 个测试文件，1,205 项通过、3 项既有跳过；类型检查与生产构建通过。连续 13 页的 V1／V2 参数验证通过；本轮未调用真实 AI 或 NAI 生图。近距离人物串衣仍受模型能力影响，实际改善需成图验证。NAI V5 Medium 原有自定义负面词限制保持不变。

更新后刷新客户端。模型、推理、合批数量、并发与现有设置沿用原配置。此前未确认的其他提示词审计改动未包含在本版。
